# Dynamic Island (Fabric, Minecraft 26.2)

Клиентский мод. **Никакой сети**: нет пакетов, каналов, серверной части
(`"environment": "client"`), поэтому он не может рвать соединение с сервером
и ставится только у тебя.

## Что делает
- **Обычный остров** (по умолчанию): голова твоего скина, рядом ник, ниже HP.
- **Сообщение в чате**: остров "выпрыгивает" с пружинной анимацией, показывает
  голову отправителя, ник и текст **10 секунд** (внизу полоска таймера).
  Если сообщений много, они идут по очереди (каждое минимум 2.5 с).
- **J** → остров раскрывается в "полный Jade": что у тебя под прицелом
  (блок / моб / игрок, мод-источник, HP цели) + твоя строка (HP, еда, координаты).
- **J ещё раз** → снова обычный остров.
- Клавишу можно сменить: Настройки → Управление → Dynamic Island.

## Требования
Java 25, Fabric Loader 0.19.3+, Fabric API 0.161.0+26.2 (или новее для 26.2).

## Сборка
### Вариант А — без установки чего-либо (GitHub Actions)
1. Залей эту папку в новый репозиторий на GitHub.
2. Вкладка **Actions** → workflow **build** → скачай артефакт `dynamicisland-jar`.

### Вариант Б — локально
Нужен JDK 25 и Gradle 9.5.1:
```
gradle build
```
Готовый jar: `build/libs/dynamicisland-1.0.0.jar`.

## Установка
Положи jar и Fabric API в папку `mods`.
